# Skill: `pos-ecommerce-ux-law` (Ley Canónica de Diseño E-Commerce)

- **Fundamento normativo:** [[ARQ-07-Ley-Diseno-Ecommerce-Navegacion-UIUX]] §0 (14 mandamientos) y 13 figuras normativas.
- **Evidencias:** `docs/vault/assets/ecommerce-design-law/` (Fig. 1 a Fig. 13).
- **Alcance:** Storefront (`StorefrontLayout`). El Portal Admin se rige por ARQ-08.
- **Precedencia:** [[DISENO-SSOT]].

## Propósito

Aplicar los **14 mandamientos de ARQ-07 §0** sin mantener una lista paralela. Si el mandamiento y una guía visual chocan, gana ARQ-07.

## Cómo se usa

1. Leer ARQ-07 §0 y la sección específica del flujo (PDP, carrito, checkout, filtros).
2. Verificar la figura normativa correspondiente.
3. Reportar el cumplimiento citando el número de mandamiento y la figura; no reescribir la regla.
